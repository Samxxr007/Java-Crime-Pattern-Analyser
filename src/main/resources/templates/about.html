Important Disclaimer
SYNTHETIC DATASET — ACADEMIC DEMONSTRATION ONLY
The crime data used by this application is entirely fictional and programmatically generated. It does not represent official Chennai crime statistics, actual crime incidents, or any law-enforcement data. Any resemblance to real events is coincidental.

This project is a college capstone submission designed to demonstrate Java programming concepts, Spring Boot architecture, and data analysis techniques using a safe, synthetic dataset.
